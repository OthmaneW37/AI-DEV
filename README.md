# TP Machine Learning : classification des iris

Ce dépôt contient un notebook pédagogique pour Google Colab : [tp0.ipynb](tp0.ipynb).

[Ouvrir le notebook dans Google Colab](https://colab.research.google.com/github/OthmaneW37/AI-DEV/blob/main/tp0.ipynb)

Le TP couvre le chargement d'un [CSV public](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/iris.csv), l'exploration des données, la séparation entraînement/test, une régression logistique avec scikit-learn, les métriques de classification, la validation croisée et la prédiction d'une nouvelle fleur.

Dans Colab, choisissez **Exécution > Tout exécuter**. Aucun compte supplémentaire ni clé API n'est nécessaire pour accéder au jeu de données.
